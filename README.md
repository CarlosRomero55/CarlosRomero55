## 🗺️ Misiones completadas

### 🦐 [Shrimp Intelligence Ecuador: de la piscina al mercado mundial](https://github.com/CarlosRomero55/shrimp-intelligence-ecuador)

¿Qué tan arriesgada es la dependencia de Ecuador de pocos mercados para su camarón, y qué pasa con los ingresos si el principal comprador baja su precio?

| 🏆 Logro desbloqueado | Detalle |
|---|---|
| 💰 Datos del sector | USD 8.401 M exportados en 2025 (BCE), conciliados con UN Comtrade |
| 🏗️ Arquitectura | Medallion en MySQL: bronze → silver (3FN) → gold (estrella) |
| ⚙️ Pipeline | ETL en Python, idempotente e incremental, con registro de ejecuciones |
| 🧪 Calidad | 141 pruebas automatizadas con pytest |
| 🔌 API | FastAPI con 7 endpoints y usuario de solo lectura |
| 📊 Dashboard | 5 páginas en Power BI, con simulador de escenarios de precio y volumen |
